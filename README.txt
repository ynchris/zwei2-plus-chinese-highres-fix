《双星物语2 Plus》Steam 汉化版高分辨率白屏修复 v1.0.0

作者：ynchris（汉化老兵）

【作用】
修复 Steam 版安装旧汉化补丁后，在开启“使用后台缓存”时，
2K、4K 等高分辨率下人物和场景白屏的问题。

【安装方法】
1. 请先安装 Steam 版《双星物语2 Plus》和汉化补丁。
2. 如果需要温泉剧情，请先安装温泉剧情补丁；如需日文语音，也请先安装日文语音补丁。
3. 最后再安装本高分辨率修复补丁。将本压缩包内全部文件解压到游戏根目录，和 ZWEI2PDX9.exe 放在一起。
4. 双击 Install.cmd，安装完成后启动游戏。
5. 打开游戏设置程序 config.exe，勾选“使用后台缓存”。

也可以不复制到游戏目录，直接运行 Install.cmd，再选择游戏根目录。

【卸载方法】
双击 Uninstall.cmd。程序会恢复安装时自动备份的原文件。

【注意事项】
本补丁仅支持已知的 2010 年汉化主程序；检测到其他版本时不会修改文件。
已测试 3840×2160 分辨率。游戏本身仍限制为约 60 FPS。
温泉剧情尚缺少对应进度存档进行完整实机验证，欢迎测试后在 GitHub Issues 反馈。
