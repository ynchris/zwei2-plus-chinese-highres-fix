# 《双星物语2 Plus》汉化版高分辨率白屏修复

[English README](README.en.md)

本项目修复旧汉化主程序在开启“使用后备缓冲区/特效缓存”后，分辨率宽或高超过 2048 像素时，3D 人物与场景变成白屏的问题。影片与字幕不受影响的原始症状，正是特效缓存纹理创建被程序内部上限拒绝所致。

## 修复内容

旧汉化主程序在调用 Direct3D 前执行以下检查：

```text
00468E76  cmp width,  0x800
00468E84  cmp height, 0x800
```

安装器只将这两处上限从 2048（`0x800`）改为 4096（`0x1000`），并安装测试中使用的 [d3d8to9 v1.15.1](https://github.com/crosire/d3d8to9) D3D8→D3D9 转译层。

本项目**不包含**游戏主程序、汉化文本、温泉事件数据、日文语音或其他游戏版权资源。

## 支持的主程序

安装器只接受已知的 2010 年汉化主程序：

```text
原始 SHA-256：F132FE28EC24393C5FD885BEA593F481B8F5D502C3D68ECAEF9C3A1F3ABFB6B2
修补 SHA-256：C2668F2B546B8491C4AC32A5D2839CE2AD52F1506BB60A34F7BF8D982BA0C882
```

遇到未知文件时，安装器会在修改任何内容前退出。

## 安装方法

1. 安装 Steam 版游戏。
2. 安装你合法取得的中文补丁。
3. 根据需要安装温泉剧情恢复补丁和日文语音补丁。
4. 双击 `Install.cmd`，选择包含 `ZWEI2PDX9.exe` 的游戏目录；也可以先把本补丁包复制到游戏根目录再运行。
5. 在游戏设置程序中开启“使用后备缓冲区/特效缓存”。

安装器会同时修补 `ZWEI2P.exe` 与 `ZWEI2PDX9.exe`，创建 `.highres-fix.backup` 备份，随后校验结果。如果目录中已有其他版本的 `d3d8.dll`，安装器会拒绝覆盖。

如果旧汉化或温泉补丁器在含中文字符的路径中显示乱码或运行失败，请临时从纯 ASCII 的物理路径安装它。

## 卸载

双击 `Uninstall.cmd`。卸载器只恢复通过哈希校验的备份；仅当 `d3d8.dll` 原本由本安装器添加时才会将其移除。

## 已验证配置

- Steam 资源与已知的 2010 年汉化主程序
- 3840×2160 窗口渲染
- 特效缓存开启（`USEBKB=1`）
- 内部 4096×4096 特效纹理
- 稳定 60 次 Present/秒
- 中文文本及日文语音替换
- NVIDIA GeForce RTX 2070 Max-Q、Windows 10

温泉剧情补丁的文件行为已经检查，但测试期间没有实际触发该剧情。欢迎有对应进度存档的玩家测试完整温泉剧情，并通过 GitHub Issue 反馈触发、文本、动画或稳定性方面的结果。

## 已知行为

- 即使桌面刷新率为 144 Hz，所测汉化主程序仍以 60 FPS 渲染。
- 4K 的显存占用明显高于 1080p。
- 本补丁不支持内部特效纹理超过 4096 的任意超高分辨率。
